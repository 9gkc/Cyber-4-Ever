# Curriculum Sources

Cyber 4 Ever uses external materials as curated references rather than reproducing their content. The platform directs learners to official resources and keeps all practice framed by authorization, scope, and responsible disclosure.

| Source | How Cyber 4 Ever uses it | URL |
| --- | --- | --- |
| NICE Workforce Framework for Cybersecurity | Informs the role-oriented organization of learning tracks and the relationship between knowledge, skills, tasks, and work roles. | https://niccs.cisa.gov/tools/nice-framework |
| OWASP Web Security Testing Guide | Supports the defensive web-security learning path and links learners to versioned, official testing guidance. | https://owasp.org/www-project-web-security-testing-guide/ |
| OWASP Juice Shop | Listed only as a purpose-built, intentionally vulnerable environment for training and awareness. | https://owasp.org/www-project-juice-shop/ |
| PortSwigger Web Security Academy | Listed as an official browser-based training resource. | https://portswigger.net/web-security |
| TryHackMe | Listed as a guided-learning provider; users must follow the rules of each room. | https://tryhackme.com/ |
| Hack The Box Academy | Listed as a structured educational environment; users must follow its terms and learning-module scope. | https://academy.hackthebox.com/ |

The platform does not claim affiliation, accreditation, endorsement, or ownership of any external source.
