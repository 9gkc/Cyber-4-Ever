# Security Policy

## Supported version

The default branch contains the supported release of Cyber 4 Ever.

## Reporting a vulnerability

Please **do not** disclose a suspected vulnerability in a public issue, discussion, pull request, or social-media post. Open a private GitHub security advisory for this repository, including a concise impact description, reproducible steps, affected files or release, and a suggested mitigation when available.

This project is a static educational web application. Reports are especially welcome for issues involving client-side data exposure, unsafe external links, dependency risk, content that weakens authorized-practice boundaries, or an incorrect claim about evidence verification.

Reports that require interaction with third-party systems must remain within the reporter’s authorized scope. Do not submit real user data, access tokens, credentials, or data captured from systems you do not control.

## Scope boundaries

Cyber 4 Ever deliberately does not run scans, enumerate targets, discover assets, execute exploit payloads, or retain learner data on a server. Requests to add such functionality are out of scope for the project’s security model.
