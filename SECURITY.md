# Security Policy

## Supported Version

The default branch contains the supported release of Cyber 4 Ever.

## Responsible Use

Cyber 4 Ever is a static educational web application focused on privacy-first cybersecurity learning. It deliberately does not run scans, enumerate targets, discover assets, execute exploit payloads, or retain learner data on a server.

## Reporting a Vulnerability

Please **do not** disclose a suspected vulnerability in a public issue, discussion, pull request, or social-media post.

1. Prefer opening a private GitHub security advisory for this repository.
2. Otherwise contact the repository owner through the GitHub profile at https://github.com/9gkc.

Include a concise impact description, reproducible steps, affected files or release, and a suggested mitigation when available.

Reports are especially welcome for issues involving client-side data exposure, unsafe external links, dependency risk, content that weakens authorized-practice boundaries, or an incorrect claim about evidence verification.

Do not submit real user data, access tokens, credentials, or data captured from systems you do not control.

## Scope Boundaries

Requests to add scanning, exploitation, or server-side data retention functionality are out of scope for the project’s security model.
