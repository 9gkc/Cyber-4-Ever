# Contributing to Cyber 4 Ever

Thank you for improving a learning resource for cybersecurity students. Contributions should preserve the platform’s three non-negotiable principles: **authorized practice**, **privacy by default**, and **evidence over unsupported claims**.

## Development checks

Install dependencies with `pnpm install --frozen-lockfile`, then run `pnpm test` and `pnpm build` before proposing a change. Keep every user-facing string clear, concise, and professional in English. URLs and code identifiers should retain their natural left-to-right direction.

## Content standards

Only add links to official, purpose-built, or explicitly authorized educational environments. Explain concepts defensively and do not introduce material that helps a user target systems outside an authorized lab. Do not add fabricated testimonials, student achievements, certificates, or claims of institutional affiliation.

## Pull requests

Describe the learning outcome, affected paths, safety impact, and the tests you ran. Keep each change focused and do not include credentials, private notes, personal data, or proprietary training materials.
